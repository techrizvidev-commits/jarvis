# JARVIS — AI Assistant

**JARVIS** is a real-time personal assistant for Windows + Android. It controls your whole PC, answers any question, writes code, and works in any language. Phone link is optional — JARVIS works fully on the PC alone.

## Download (easiest — nothing else to install)

1. Go to **Releases** on this repo.
2. **Windows:** download `Jarvis.exe`, double-click it. The HUD opens in your browser. Done.
3. **Android:** download `Jarvis.apk`, install it, open the app, enter your laptop IP once — or scan the QR code on the laptop HUD. Same Wi-Fi as the laptop.

See SETUP.md for the 60-second guide, API.md for all commands, SELLER.md + LICENSE for the commercial licence.
